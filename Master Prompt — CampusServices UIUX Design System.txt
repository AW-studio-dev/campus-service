# ARCHITECTURE TECHNIQUE & SÉCURITÉ
- **Framework** : Flutter (Dart)
- **Gestion d'état** : Riverpod (avec `StateNotifier` pour les états complexes).
- **Navigation** : GoRouter (avec des `redirect` stricts basés sur l'état d'authentification).
- **Backend** : Supabase (Auth, Database, Storage).
- **Configuration** : Utiliser `flutter_dotenv` pour charger `SUPABASE_URL` et `SUPABASE_ANON_KEY`. **Ne jamais hardcoder les clés. Ne jamais mettre la clé `service_role` dans Flutter.**
- **Responsive** : Utiliser `LayoutBuilder` et `MediaQuery` pour des layouts spécifiques Mobile (< 768px), Tablet (768-1199px) et Desktop (> 1200px).

# 🛡️ RÈGLES DE SÉCURITÉ ABSOLUES (À APPLIQUER À CHAQUE LIGNE DE CODE)
1. **Authentification** : Écouter en permanence `Supabase.instance.client.auth.onAuthStateChange`. Si la session expire, rediriger immédiatement vers la page de Login. Protéger toutes les routes privées via GoRouter.
2. **Validation des entrées** : Utiliser `TextFormField` avec des `validator` stricts pour tous les formulaires (email, mot de passe, nom, prix). Ne jamais faire confiance aux données saisies par l'utilisateur.
3. **Gestion des erreurs** : Envelopper chaque appel Supabase dans un `try/catch`. Afficher des messages d'erreur **génériques** à l'utilisateur (ex: "Une erreur est survenue", "Email ou mot de passe incorrect"). **Ne jamais afficher l'erreur brute de PostgreSQL** (cela pourrait révéler la structure de la base).
4. **Sécurité du Storage** : Avant d'uploader un fichier (avatar, post, service), valider son type MIME (image/jpeg, image/png) et sa taille (ex: max 5 Mo). Utiliser des noms de fichiers uniques (`UUID + extension`) pour éviter d'écraser les fichiers des autres.
5. **Respect des RLS** : Le code Flutter doit être conçu en sachant que la base de données refusera les actions non autorisées. Par exemple, si un utilisateur essaie de modifier le post d'un autre, l'UPDATE retournera 0 ligne. Gérer ce cas proprement dans l'UI.
6. **Déconnexion** : Vider toutes les données sensibles de l'état local (Riverpod) lors de la déconnexion.
